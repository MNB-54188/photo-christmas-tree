使用说明

🖐️ 手势控制

  • 🖐 张开手掌左右移动 = 旋转；手举高 = 俯视，放中间 = 正视，压低 = 仰视
  • 🤏 捏合拇指食指捏住后张开 = 放大，捏紧 = 缩小
  • 🤏🤏 双手捏合两手拉开 = 放大，靠拢 = 缩小
  • ✌️ 比耶下一张照片（没打开时先打开正中的那张）
  • ☝️ 伸食指关闭照片放大界面（仅在打开照片时生效，不会误触）
  • 🤟 三指上一个造型
  • 🖖 四指下一个造型
  • ✊ 握拳收回成圣诞树造型

🖱️ 鼠标 / 触屏

  • 拖拽 = 旋转　·　滚轮 / 双指 = 缩放　·　单击照片 = 放大查看
  • 键盘：1~6 切换造型，空格 自动旋转，G 手势开关

☁️ 照片存储

  • 部署到 Cloudflare 后：照片二进制存 KV，元信息存 D1，多设备共享。
  • 未部署 / 接口不可用时自动降级为浏览器本地存储，功能完全可用。

🔒 照片密码（可选）

  • 若已启用密码，上传和删除照片都会弹框要求输入，正确后本次会话内不再询问（关掉标签页需重输）。
  • 线上在服务端校验，绕过页面直接调接口会被拒绝；未启用时任何人都能上传或删除。
